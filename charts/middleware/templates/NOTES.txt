Middleware {{ .Chart.AppVersion }} is deployed as release {{ .Release.Name }} in
namespace {{ .Release.Namespace }}.

1. Access

{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  Web UI: http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}/
{{- end }}
{{- else }}
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "middleware.fullname" . }} 3000:{{ .Values.service.port }}
  Open http://localhost:3000/
{{- end }}

2. Readiness

  kubectl wait --for=condition=available deployment/{{ include "middleware.fullname" . }} -n {{ .Release.Namespace }} --timeout=300s
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

The pod becomes Ready only after the frontend, analytics, sync, and embedded
Redis listeners are available.

3. Configuration

  PostgreSQL: {{ if .Values.postgresql.enabled }}bundled at {{ include "middleware.dbHost" . }}:{{ include "middleware.dbPort" . }}{{ else }}external at {{ .Values.externalDatabase.host }}:{{ .Values.externalDatabase.port }}{{ end }}
  Redis: embedded upstream process on localhost:6385
  Frontend: {{ .Values.middleware.frontendPort }}
  Analytics: {{ .Values.middleware.analyticsPort }}
  Sync: {{ .Values.middleware.syncPort }}

4. Persistence and backups

  Key storage: {{ if .Values.persistence.enabled }}PVC {{ include "middleware.dataClaimName" . }} mounted at /app/backend/analytics_server/mhq/config{{ else }}ephemeral emptyDir; unsuitable for production{{ end }}

Back up PostgreSQL and the key PVC as one recovery set. Restoring only the
database can leave encrypted integration credentials unreadable.

5. Security

The ServiceAccount token is {{ if .Values.serviceAccount.automountServiceAccountToken }}mounted by explicit configuration{{ else }}not mounted{{ end }}. Database passwords are read from Kubernetes Secrets. Review unrestricted egress before applying cluster-wide default-deny policies.

6. Observability

  kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "middleware.fullname" . }} -c migrate-database
  kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "middleware.fullname" . }} -c middleware --tail=200
  kubectl get events -n {{ .Release.Namespace }} --sort-by=.lastTimestamp

7. Troubleshooting

  kubectl describe pod -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl get endpoints -n {{ .Release.Namespace }} {{ include "middleware.fullname" . }}
  kubectl exec -n {{ .Release.Namespace }} deployment/{{ include "middleware.fullname" . }} -c middleware -- test -s /app/backend/analytics_server/mhq/config/config.ini

If migrations wait for PostgreSQL, verify the Service, Secret key, SSL mode,
and NetworkPolicy path. If the UI listens but the pod is not Ready, inspect the
analytics and sync process logs.

8. Upgrade

Preserve the key PVC and PostgreSQL credential Secret. Remove legacy
redis.enabled or externalRedis.enabled overrides; Middleware 0.3.1 supports
only its loopback Redis runtime safely.
