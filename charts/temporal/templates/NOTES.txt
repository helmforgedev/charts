3. Getting started
==================

Wait for every Temporal role:
  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "temporal.componentName" (dict "root" . "component" "frontend") }} --timeout=10m
  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "temporal.componentName" (dict "root" . "component" "history") }} --timeout=10m
  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "temporal.componentName" (dict "root" . "component" "matching") }} --timeout=10m
  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "temporal.componentName" (dict "root" . "component" "worker") }} --timeout=10m

Run the chart health test:
  helm test {{ .Release.Name }} -n {{ .Release.Namespace }} --logs

Create a namespace from the admin tools pod:
  kubectl -n {{ .Release.Namespace }} exec deployment/{{ include "temporal.componentName" (dict "root" . "component" "admin-tools") }} -- temporal operator namespace create --namespace production

List namespaces:
  kubectl -n {{ .Release.Namespace }} exec deployment/{{ include "temporal.componentName" (dict "root" . "component" "admin-tools") }} -- temporal operator namespace list

5. Configuration summary
========================

Server roles:
  frontend replicas: {{ .Values.server.components.frontend.replicaCount }}
  history replicas: {{ .Values.server.components.history.replicaCount }}
  matching replicas: {{ .Values.server.components.matching.replicaCount }}
  worker replicas: {{ .Values.server.components.worker.replicaCount }}
  Web UI replicas: {{ .Values.web.replicaCount }}

Production guidance:
  - Size and scale each role independently from observed Temporal metrics.
  - Use topology spread or anti-affinity across failure domains.
  - Protect every replica set with an intentional PodDisruptionBudget.
  - Back up PostgreSQL and test database restore procedures.
  - Terminate TLS at the Gateway or configure end-to-end TLS externally.
  - Do not expose frontend gRPC without authentication and network controls.

7. Troubleshooting
==================

Recent events:
  kubectl -n {{ .Release.Namespace }} get events --sort-by=.lastTimestamp

All Temporal logs:
  kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/name={{ include "temporal.name" . }} --all-containers --prefix --tail=200

Previous container logs:
  kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/name={{ include "temporal.name" . }} --all-containers --previous --prefix --tail=200

If server pods wait in init containers, inspect the schema Job and PostgreSQL
logs first. External databases must already contain both configured databases,
and the supplied user must own or be able to manage both Temporal schemas.

If a GRPCRoute is not Accepted, confirm that the Gateway has a compatible gRPC
listener and that its controller supports the v1 GRPCRoute resource. The chart
uses kubernetes.io/h2c for the plaintext backend protocol.

If the UI is healthy but cannot reach Temporal, inspect the frontend Service,
EndpointSlice, frontend logs, and TEMPORAL_ADDRESS in the Web UI pod.
