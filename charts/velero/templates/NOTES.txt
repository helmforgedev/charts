1. Application overview:
   Velero is an open-source backup, disaster recovery, and cluster migration tool for Kubernetes.
   It provides point-in-time snapshots and scheduled backups of cluster state, CRDs, and persistent volumes.
   Deployed as a centralized controller with optional node-agent DaemonSet for file-system-level backups.

5. Backup and restore operations:
   Create an immediate on-demand backup:
     velero backup create <backup-name> --include-namespaces <namespace> -n {{ .Release.Namespace }}
   Describe backup details and progress:
     velero backup describe <backup-name> -n {{ .Release.Namespace }} --details
   Restore a backup into the cluster:
     velero restore create --from-backup <backup-name> -n {{ .Release.Namespace }}
   Inspect recent backup logs:
     velero backup logs <backup-name> -n {{ .Release.Namespace }}

7. Operational guidelines and best practices:
   - Object Storage Verification:
       Validate bucket connectivity and IAM permissions before relying on Velero for production disaster recovery.
   - S3-Compatible Storage:
       If using MinIO or Ceph, verify that s3Url and s3ForcePathStyle are correctly configured in backupStorageLocations.
   - Scheduling Policy:
       Confirm scheduled backups have realistic TTL (.Values.configuration.defaultBackupTTL) and retention policies.
   - Disaster Recovery Drill:
       Periodically test restores into an isolated staging namespace to confirm snapshot integrity and application recovery.
