3. Getting started
==================

Wait until the Deployment is available:

  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "bulwark-mail.fullname" . }} --timeout=180s

{{- if eq .Values.config.mode "wizard" }}

Wizard mode is active. Open the service and follow `/setup` to configure:

  - the public URL of the external JMAP server;
  - the Bulwark administrator password;
  - optional OAuth/OIDC login;
  - branding and feature policy.

The wizard writes state below `/app/data`; persistence is mandatory so that
the completed setup survives pod replacement.
{{- else }}

Declarative mode is active. The chart configured:

  - JMAP URL: {{ .Values.config.jmap.serverUrl }}
  - settings sync: {{ .Values.config.settingsSync }}
  - Stalwart features: {{ .Values.config.stalwartFeatures }}
  - OAuth enabled: {{ .Values.config.oauth.enabled }}

The JMAP URL is managed through JMAP_SERVER_URL. Existing files on a reused
PVC retain higher upstream precedence; remove obsolete admin overrides before
switching an existing installation to declarative mode.
{{- if .Values.config.admin.readOnly }}
Admin configuration is read-only because config.admin.readOnly is enabled.
{{- else }}
Admin configuration remains writable. Enable config.admin.readOnly only after
bootstrap has persisted the intended admin configuration.
{{- end }}
{{- end }}

7. Troubleshooting
==================

List pods and recent events:

  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl -n {{ .Release.Namespace }} get events --sort-by=.lastTimestamp

Inspect the pod and logs:

  kubectl -n {{ .Release.Namespace }} describe pod -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "bulwark-mail.fullname" . }} --tail=200
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "bulwark-mail.fullname" . }} --previous --tail=200

If the browser cannot reach JMAP, verify that the configured URL is public to
the browser and that Stalwart permits credentialed CORS for the Bulwark origin.
A Kubernetes `.svc` hostname is usually not browser-resolvable.

If the pod reports a read-only filesystem error, confirm that all application
state remains below `/app/data` and temporary files below `/tmp`.

If the wizard restarts after pod replacement, verify the PVC is Bound and is
mounted at `/app/data`.

If OAuth login fails, inspect issuer discovery from the pod and verify the
client redirect URI, scopes, and Secret key names.
