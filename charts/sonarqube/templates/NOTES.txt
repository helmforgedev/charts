7. Backup Boundary

Back up PostgreSQL and the data and extensions volumes as one recovery set.
The logs volume is optional and is not application state.

## Production

8. Production Checklist

- Use bundled or external PostgreSQL for durable environments.
- Prepare node kernel settings before enabling Elasticsearch bootstrap checks.
- Enable NetworkPolicy only after allowing database and plugin artifact traffic.
- Pin compatible plugin versions and configure SHA-256 checksums.
- Test database and persistent-volume restoration regularly.
