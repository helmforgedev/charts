4. Persistence
==============
Enabled: {{ .Values.persistence.enabled }}
Claim: {{ include "stirling-pdf.claimName" . }}
Generated claim retained on uninstall: {{ .Values.persistence.retain }}

5. Availability and resources
=============================
Never scale Community H2 to multiple writers, including on RWX storage.
Java shares memory with OCR and office tools. Size resources against real documents.

6. Monitoring and network
=========================

kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "stirling-pdf.fullname" . }} -c stirling-pdf

7. Upgrade and recovery
=======================
Quiesce and archive the complete claim before upgrades.
Restore into a fresh claim and set persistence.existingClaim.
Verify native login and authenticated conversion. Helm rollback does not undo migrations.
