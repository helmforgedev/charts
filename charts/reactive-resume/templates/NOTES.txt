PostgreSQL: {{ include "reactive-resume.databaseHost" . }}
Native v5 PDF generation does not require Browserless.

6. Isolation and health

An enforcing CNI and trusted namespace policy ownership are prerequisites.
The helper checks each Pod IP family before private native enrollment.
Never allow direct access to native port 3010 from other Pods.
Native health checks PostgreSQL and storage; it is not a Prometheus endpoint.

7. Upgrades and recovery

Migrations run before public startup. The single Recreate workload has downtime.
An existing user database without its identity marker blocks initialization.
Back up and restore database, files and matching identity Secrets together.

8. Troubleshooting

Inspect the admission helper and bootstrap logs before the server logs.
Check CNI policies, helper Service addresses, dependency credentials and CA trust.
Public signup remains disabled during ordinary operation.
