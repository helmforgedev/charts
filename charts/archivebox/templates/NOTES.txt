5. Availability and resources
==============================
Recreate upgrades intentionally include downtime and prevent concurrent writers.
Never scale the Deployment or attach /data to another running ArchiveBox Pod.
Set CPU and memory for Chromium and size the PVC for capture volume and retention.

6. Monitoring and network
=========================
kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "archivebox.fullname" . }} --tail=100
Monitor capture failures, Chromium memory, PVC growth, restarts, and backup age.
ArchiveBox captures untrusted websites; control outbound access at the platform.

7. Upgrade and recovery
=======================
Quiesce and back up /data before upgrades that may change storage formats.
helm upgrade {{ .Release.Name }} helmforge/archivebox -n {{ .Release.Namespace }} -f values.yaml
kubectl rollout status -n {{ .Release.Namespace }} deployment/{{ include "archivebox.fullname" . }}
Restore the complete dataset into an isolated claim before replacing production.
Helm rollback does not reverse SQLite or archive migrations.
