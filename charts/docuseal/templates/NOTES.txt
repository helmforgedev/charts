3. Getting started
==================
Wait for the migration Job and Deployment:
  kubectl -n {{ .Release.Namespace }} wait --for=condition=complete job/{{ include "docuseal.fullname" . }}-migrate --timeout=10m
  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "docuseal.fullname" . }}
Create the first administrator through /setup. No administrator password is
stored in chart values.

7. Troubleshooting
==================
  kubectl -n {{ .Release.Namespace }} get events --sort-by=.lastTimestamp
  kubectl -n {{ .Release.Namespace }} logs job/{{ include "docuseal.fullname" . }}-migrate
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "docuseal.fullname" . }}
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "docuseal.fullname" . }} --previous
Check database, Redis, storage, SMTP, Secret keys, and private egress peers.

8. Backup, upgrade, and resources
================================
Back up PostgreSQL, attachments, Redis queues, and the application Secret as
one recovery set. Test restoration in an isolated namespace. The pre-upgrade
migration hook can change the database schema, so an image rollback alone is
not a complete rollback procedure.
