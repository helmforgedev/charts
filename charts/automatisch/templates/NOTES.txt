===================
  1. Wait for the web Deployment to become available.
  2. Open the web UI and create the first administrator account.
  3. Configure integration credentials and create a test workflow.
  4. Confirm the worker executes the test workflow.

      deployment/{{ include "automatisch.fullname" . }} --tail=100 -f

6. Security reminders
=====================
  Back up Secret {{ include "automatisch.appSecretName" . }} together with PostgreSQL.
  Do not rotate encryption-key, app-secret-key, or webhook-secret-key casually.
  Use TLS at the ingress or edge proxy for every public installation.
  Review NetworkPolicy egress before using strict destination allowlists.

7. Backup and restore
=====================
  Stream the application Secret directly into an encrypted backup:
    kubectl get secret -n {{ .Release.Namespace }} \
      {{ include "automatisch.appSecretName" . }} -o yaml | \
      age --encrypt --recipient "$AGE_RECIPIENT" \
      > automatisch-app-secret.yaml.age

  Back up PostgreSQL with the tooling appropriate to the selected deployment.
  Restore PostgreSQL and the matching application Secret into an isolated
  namespace, then execute a real workflow before accepting the recovery.

8. Troubleshooting
==================
  Web pod waiting for PostgreSQL:
    kubectl logs -n {{ .Release.Namespace }} \
      deployment/{{ include "automatisch.fullname" . }} -c wait-for-db

  Workflows remain queued:
    kubectl describe deployment -n {{ .Release.Namespace }} \
      {{ include "automatisch.fullname" . }}-worker
    kubectl logs -n {{ .Release.Namespace }} \
      deployment/{{ include "automatisch.fullname" . }}-worker --tail=200

  Inspect all release resources:
    kubectl get all -n {{ .Release.Namespace }} \
      -l app.kubernetes.io/instance={{ .Release.Name }}

9. Upgrading
============
  Back up PostgreSQL and the application Secret before every upgrade.
  Validate migrations and a worker-executed test workflow in staging.
  Upgrade with readiness waiting enabled:
    helm upgrade {{ .Release.Name }} helmforge/automatisch \
      -n {{ .Release.Namespace }} --reuse-values --wait --timeout 10m
