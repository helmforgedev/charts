1. Access RustFS

   Cluster URL:
   http://{{ include "rustfs.fullname" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}

   Confirm the workload:
   kubectl -n {{ .Release.Namespace }} get statefulset,pod,svc -l app.kubernetes.io/instance={{ .Release.Name }}

2. Retrieve Authentication Credentials

   Root credentials and access keys are stored in Secret: {{ include "rustfs.secretName" . }}

   For clustered setups, RPC secret: {{ default (printf "%s-rpc" (include "rustfs.fullname" .)) .Values.auth.rpcExistingSecret }}

3. Port-Forward for Local Administration

   S3 API: kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "rustfs.fullname" . }} 9000:{{ .Values.service.port }}

{{- if .Values.config.consoleEnabled }}
   Console: kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "rustfs.fullname" . }}-console 9001:{{ .Values.consoleService.port }}
{{- else }}
   Console access is disabled by config.consoleEnabled=false.
{{- end }}

4. Configure Ingress and TLS

   Public exposure must use HTTPS because S3 credentials and payloads
   are unsafe over plain HTTP. Configure ingress.
   Configure TLS termination and matching DNS records.

5. Verify Health and Probes

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "rustfs.fullname" . }} 9000:{{ .Values.service.port }}
   curl --fail http://127.0.0.1:9000/health

   The health endpoint checks the HTTP process, not an authenticated S3 write/read cycle.

   Application listeners: API {{ .Values.containerPorts.api }}, console {{ .Values.containerPorts.console }}.
   Client-facing Service ports can differ from those process listeners.

   NetworkPolicy allows release-namespace clients by default. Configure explicit
   API and console peers before admitting clients from other namespaces.

6. Configure Observability and Monitoring

   RustFS pushes metrics, traces, and logs over OTLP (OpenTelemetry Protocol).

   Point RUSTFS_OBS_ENDPOINT at an OpenTelemetry Collector to export Prometheus metrics.

7. Replication and Backup Operations

   Back up storage volumes before upgrading or altering topology.

   Do not change topology or replicaCount on an existing clustered deployment.

8. Review Operational Guidance

   See https://helmforge.dev/docs/charts/rustfs for scaling, backup and recovery guidance.

   RustFS documentation and reference architecture: https://rustfs.com

Happy Helmforging :)
