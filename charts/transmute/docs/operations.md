# Transmute Operations Guide

## Initial Setup

Deploy the chart with default persistent storage and an autogenerated secret key:

```bash
helm repo add helmforge https://repo.helmforge.dev
helm install transmute helmforge/transmute --namespace media --create-namespace
```

## OIDC Authentication

Configure OpenID Connect Single Sign-On with your identity provider (Keycloak, Authentik, Okta):

```yaml
oidc:
  enabled: true
  providerUrl: "https://auth.example.com/realms/master"
  clientId: "transmute"
  clientSecret: "secret-token"
  redirectUri: "https://transmute.example.com/api/auth/oidc/callback"
```

## External Secrets Operator (ESO)

Integrate with HashiCorp Vault or AWS Secrets Manager:

```yaml
externalSecrets:
  enabled: true
  secretStoreRef:
    name: vault-backend
    kind: SecretStore
  data:
    - secretKey: TRANSMUTE_SECRET_KEY
      remoteRef:
        key: secret/transmute
        property: secretKey
```
