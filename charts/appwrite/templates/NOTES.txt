4. Getting started

  Wait for every Appwrite workload to become Ready:

    kubectl wait --for=condition=ready pod -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }} --timeout=600s

  Open the Console through the configured shared origin, create the first
  account, and then create a project. Functions and Sites execution require an
  external executor/orchestrator and are not provisioned by this chart.

5. Validation commands

  Confirm the API version and the three Service endpoints:

    kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "appwrite.fullname" . }}-api -c api -- curl -fsS http://127.0.0.1:{{ .Values.api.containerPort }}/v1/health/version
    kubectl get endpoints -n {{ .Release.Namespace }} {{ include "appwrite.fullname" . }}-api {{ include "appwrite.fullname" . }}-console {{ include "appwrite.fullname" . }}-realtime

  Confirm that no Appwrite container restarted:

    kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

6. Operations and upgrades

  Before upgrading, back up MariaDB, every shared Appwrite PVC, and the
  application Secret. Review the chart upgrade notes, pause traffic for schema
  changes, upgrade, and then run the upstream migration:

    helm upgrade {{ .Release.Name }} oci://ghcr.io/helmforgedev/helm/appwrite -n {{ .Release.Namespace }} --reuse-values
    kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "appwrite.fullname" . }}-api -c api -- migrate

{{- if .Values.backup.enabled }}
  Scheduled backup: {{ .Values.backup.schedule }}
  Backup bucket:    {{ .Values.backup.s3.bucket }}

    kubectl get cronjob -n {{ .Release.Namespace }} {{ include "appwrite.fullname" . }}-backup
{{- else }}
  The optional S3 database backup CronJob is disabled. Production recovery
  also requires independent snapshots or backups for all shared PVCs.
{{- end }}

7. Troubleshooting

  Inspect workload state, recent events, and component logs:

    kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }} -o wide
    kubectl get events -n {{ .Release.Namespace }} --sort-by=.lastTimestamp
    kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=api --all-containers --tail=100
    kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=realtime --all-containers --tail=100
    kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=worker --all-containers --tail=100

  Verify PVC binding and NetworkPolicy objects when storage or connectivity fails:

    kubectl get pvc,networkpolicy -n {{ .Release.Namespace }}
