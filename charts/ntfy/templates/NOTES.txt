5. Validation commands
----------------------
  Wait for ntfy:
    kubectl wait --for=condition=Ready pod -n {{ $namespace }} -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=server --timeout=300s

  Check resources and storage:
    kubectl get deploy,svc,pod,pvc -n {{ $namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

  Check the health endpoint:
    kubectl run ntfy-smoke -n {{ $namespace }} --rm -i --restart=Never --image=docker.io/library/busybox:1.37 -- wget -qO- http://{{ $fullname }}:{{ .Values.service.port }}/v1/health

6. Logs and troubleshooting
---------------------------
  Application logs:
    kubectl logs -n {{ $namespace }} deploy/{{ $fullname }} --tail=200

  Pod details and recent events:
    kubectl describe pod -n {{ $namespace }} -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=server
    kubectl get events -n {{ $namespace }} --sort-by=.lastTimestamp

  Rendered values and manifests:
    helm get values {{ .Release.Name }} -n {{ $namespace }}
    helm get manifest {{ .Release.Name }} -n {{ $namespace }}

7. Backup and recovery
---------------------
{{- if .Values.backup.enabled }}
  Scheduled S3 backup is enabled:
    Schedule: {{ .Values.backup.schedule }}
    Bucket:   {{ .Values.backup.s3.bucket }}
    Prefix:   {{ .Values.backup.s3.prefix }}

  Trigger a manual backup:
    kubectl create job -n {{ $namespace }} --from=cronjob/{{ $fullname }}-backup ntfy-backup-manual
{{- else }}
  Scheduled backup is disabled. Back up the data PVC and, when enabled,
  PostgreSQL before upgrades. Enable it with backup.enabled=true.
{{- end }}

8. Security and production readiness
------------------------------------
  - Set ntfy.baseUrl to the canonical HTTPS URL.
  - Use ntfy.authDefaultAccess=deny-all for private instances.
  - Keep credentials in existing Secrets or External Secrets.
  - Review explicit egress rules before enabling NetworkPolicy egress isolation.
  - Restore-test both PVC and PostgreSQL backups.
{{- if not .Values.ingress.enabled }}
  - No Ingress is enabled. Mobile push requires a reachable HTTPS endpoint.
{{- end }}
{{- if and (include "ntfy.databaseEnabled" .) (not .Values.persistence.enabled) }}
  - Persistence is disabled. PostgreSQL stores database-backed state, but
    filesystem attachments and local files will not survive pod replacement.
{{- end }}
