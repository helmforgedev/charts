2. Access
=========
  In-cluster endpoint:
    {{ $scheme }}://{{ $fullname }}.{{ $namespace }}.svc.cluster.local:{{ .Values.service.port }}

  Local access:
    kubectl port-forward svc/{{ $fullname }} 9200:{{ .Values.service.port }} -n {{ $namespace }}
{{- if $secure }}
  Read the elastic password:
    export ELASTIC_PASSWORD=$(kubectl get secret {{ include "elasticsearch.credentialsSecretName" . }} -n {{ $namespace }} -o jsonpath='{.data.elastic-password}' | base64 -d)

  Test authenticated access:
    curl -k -u elastic:${ELASTIC_PASSWORD} https://localhost:9200/_cluster/health?pretty

  Anonymous access should return HTTP 401:
    curl -k -o /dev/null -w '%{http_code}\n' https://localhost:9200/
{{- else }}
  Test access:
    curl http://localhost:9200/_cluster/health?pretty
{{- end }}

4. Validation
=============
  kubectl wait --for=condition=Ready pod -l app.kubernetes.io/component-group=elasticsearch -n {{ $namespace }} --timeout=300s
  kubectl get pods,svc,pvc -n {{ $namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

  Check Service endpoints:
    kubectl get endpointslice -n {{ $namespace }} \
      -l kubernetes.io/service-name={{ $fullname }}

  List cluster nodes:
{{- if $secure }}
    kubectl exec {{ $fullname }}-master-0 -n {{ $namespace }} -- \
      curl -ks -u elastic:${ELASTIC_PASSWORD} https://localhost:{{ .Values.containerPorts.http }}/_cat/nodes?v
{{- else }}
    kubectl exec {{ $fullname }}-master-0 -n {{ $namespace }} -- \
      curl -s http://localhost:{{ .Values.containerPorts.http }}/_cat/nodes?v
{{- end }}

  Inspect current and previous logs:
    kubectl logs {{ $fullname }}-master-0 -n {{ $namespace }} -c elasticsearch --tail=200
    kubectl logs {{ $fullname }}-master-0 -n {{ $namespace }} -c elasticsearch --previous --tail=200

  Create and query a smoke-test index after port-forwarding:
{{- if $secure }}
    curl -k -u elastic:${ELASTIC_PASSWORD} -X PUT https://localhost:9200/helmforge-smoke
    curl -k -u elastic:${ELASTIC_PASSWORD} https://localhost:9200/helmforge-smoke
{{- else }}
    curl -X PUT http://localhost:9200/helmforge-smoke
    curl http://localhost:9200/helmforge-smoke
{{- end }}

7. System prerequisite
======================
Elasticsearch requires vm.max_map_count=262144 on Kubernetes nodes. Configure
it at the node level. The privileged sysctl init container is opt-in through
sysctlInit.enabled for clusters whose security policy permits it.

  Pods pending:
    kubectl get pvc -n {{ $namespace }}
    kubectl describe pod {{ $fullname }}-master-0 -n {{ $namespace }}

  Cluster not forming:
    kubectl get endpoints {{ $fullname }}-master-headless -n {{ $namespace }}
    kubectl logs {{ $fullname }}-master-0 -n {{ $namespace }} -c elasticsearch --tail=300

  Security errors:
    kubectl get secret {{ include "elasticsearch.credentialsSecretName" . }} -n {{ $namespace }}
    kubectl get secret {{ include "elasticsearch.tlsSecretName" . }} -n {{ $namespace }}
{{- if .Values.externalSecrets.enabled }}
    kubectl get externalsecret -n {{ $namespace }}
    kubectl describe externalsecret -n {{ $namespace }}
{{- end }}

  Storage pressure:
{{- if $secure }}
    curl -k -u elastic:${ELASTIC_PASSWORD} https://localhost:9200/_cat/allocation?v
    curl -k -u elastic:${ELASTIC_PASSWORD} https://localhost:9200/_cat/shards?v
{{- else }}
    curl http://localhost:9200/_cat/allocation?v
    curl http://localhost:9200/_cat/shards?v
{{- end }}
