1. Summary

   Heimdall {{ .Chart.AppVersion }} is deployed as release {{ .Release.Name }}
   in namespace {{ .Release.Namespace }}. The application listener is port
   {{ .Values.heimdall.containerPort }} and the Service exposes port {{ .Values.service.port }}.

2. Access

{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
   Dashboard: http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}/
{{- end }}
{{- else }}
   Start a local port-forward:

     kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "heimdall.fullname" . }} 8080:{{ .Values.service.port }}

   Open http://localhost:8080/.
{{- end }}

3. Getting Started

   Wait for the server and then add application tiles in the dashboard:

     kubectl wait --for=condition=ready pod -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=server -n {{ .Release.Namespace }} --timeout=300s

4. Credentials

   Heimdall has no chart-managed login credentials. Configure access controls
   in Heimdall and protect external access with TLS and the controls provided by
   your Ingress controller. Enhanced tiles may require upstream API keys.

5. Configuration

   Persistent application state is stored in /config.
{{- if .Values.persistence.enabled }}
   Persistence is enabled{{ with .Values.persistence.existingClaim }} with existing claim {{ . }}{{ end }}.
{{- else }}
   Persistence is disabled; dashboard state is disposable.
{{- end }}
   ServiceAccount token automount: {{ .Values.serviceAccount.automountServiceAccountToken }}.
   Ingress NetworkPolicy enabled: {{ .Values.networkPolicy.enabled }}.

6. Validation

     kubectl get deployment,service,pod -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }}
     kubectl get networkpolicy -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }}
     kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "heimdall.fullname" . }} -c heimdall -- grep 'listen {{ .Values.heimdall.containerPort }} default_server' /config/nginx/site-confs/default.conf

7. Troubleshooting

     kubectl describe pod -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }}
     kubectl logs -l app.kubernetes.io/instance={{ .Release.Name }} -n {{ .Release.Namespace }} --all-containers --tail=100
     kubectl get events -n {{ .Release.Namespace }} --sort-by=.lastTimestamp

   For write failures, confirm that heimdall.puid and heimdall.pgid can write to
   the mounted /config volume.
