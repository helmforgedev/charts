3. Readiness
============

  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "guacamole.fullname" . }} --timeout=300s
  kubectl -n {{ .Release.Namespace }} get pods,service -l app.kubernetes.io/instance={{ .Release.Name }}

The probes validate the actual Tomcat and guacd listeners configured by
containerPorts.http and guacd.port.

4. Initial configuration
========================

Default administrator credentials: guacadmin / guacadmin
Change this password immediately, then create named administrators and remote
desktop connections. Configure ingress TLS before public exposure.

{{- if .Values.oidc.enabled }}
OIDC authentication is enabled for client {{ .Values.oidc.clientId }}.
{{- else if .Values.saml.enabled }}
SAML authentication is enabled for entity {{ include "guacamole.samlEntityId" . }}.
{{- else }}
Database authentication is active.
{{- end }}

5. Secrets and security
=======================

Use existing Secrets or External Secrets for production database and backup
credentials. Preserve the default non-root, read-only filesystem, seccomp,
capability, service-account-token, and NetworkPolicy controls.

After rotating an externally managed Secret, restart the Deployment:

  kubectl -n {{ .Release.Namespace }} rollout restart deployment/{{ include "guacamole.fullname" . }}

6. Backup and upgrade
=====================

{{- if .Values.backup.enabled }}
Database backups are scheduled with {{ .Values.backup.schedule }}.
{{- else }}
Chart-managed database backups are disabled.
{{- end }}

Test database restore separately, preserve credentials, and verify login plus a
representative remote session after upgrades. Backup archives do not include
the remote desktop target systems.

7. Troubleshooting
==================

  kubectl -n {{ .Release.Namespace }} describe deployment/{{ include "guacamole.fullname" . }}
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "guacamole.fullname" . }} -c guacamole --tail=200
  kubectl -n {{ .Release.Namespace }} logs deployment/{{ include "guacamole.fullname" . }} -c guacd --tail=200
  kubectl -n {{ .Release.Namespace }} get events --sort-by=.lastTimestamp

Check database schema initialization, Secret keys, listener ports, NetworkPolicy
peers, target DNS and firewall reachability, and reverse-proxy headers.
