QuestDB is available inside the cluster at:
  http://{{ include "questdb.fullname" . }}.{{ .Release.Namespace }}.svc:9000

This chart deploys exactly one OSS QuestDB instance. It does not provide HA or
replication. Keep the service internal unless transport encryption is provided
by an Ingress, Gateway or service mesh.

The generated PostgreSQL and HTTP passwords are retained in Secret
{{ include "questdb.authSecretName" . }}. Retrieve the HTTP password with:
  kubectl get secret -n {{ .Release.Namespace }} {{ include "questdb.authSecretName" . }} -o jsonpath='{.data.{{ .Values.questdb.httpPasswordKey }}}' | base64 -d

Before taking a storage snapshot, run CHECKPOINT CREATE. After the external
snapshot or copy completes, run CHECKPOINT RELEASE.

Happy Helmforging :)
