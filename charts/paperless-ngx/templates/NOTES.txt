5. Getting Started
==================
  Step 1: Log in with the superuser from section 3.
  Step 2: Upload a PDF in the web UI, or copy one into the consume directory:
            kubectl cp ./scan.pdf {{ $namespace }}/<pod>:/usr/src/paperless/consume/ -c paperless
  Step 3: Watch it in the "File Tasks" view, then search for words from the document.
  Step 4: Configure mail rules, workflows and users from the settings.

7. Backup
=========
  This chart does not schedule backups. Back up both the database and the media
  volume, or use the upstream exporter, which writes documents and metadata:
    kubectl exec -n {{ $namespace }} deploy/{{ $fullname }} -c paperless -- \
      document_exporter /usr/src/paperless/export
{{- if not (or .Values.persistence.export.enabled .Values.persistence.export.existingClaim) }}
  Enable persistence.export (or mount an existing claim) so exports survive restarts.
{{- end }}

8. Troubleshooting
==================
  Pod not ready:
    -> Check the init container logs for PostgreSQL and Valkey connectivity.
    -> The first start runs database migrations; the startup probe allows 10 minutes.

  "CSRF verification failed" when logging in:
    -> Set paperless.url to the exact public URL, including https://.

  Files in the consume directory are ignored:
    -> NFS and SMB do not support inotify. Set paperless.consumer.pollingInterval, for example 60.

  Office documents or emails fail to import:
    -> Enable tika.enabled and gotenberg.enabled.

  Additional OCR languages:
    -> The image ships eng, deu, ita, spa and fra. Installing more languages with
       PAPERLESS_OCR_LANGUAGES requires running as root, which this chart does not do by default.

9. Upgrading
============
  Back up PostgreSQL and the media volume before upgrading. Keep the secret key
  ({{ include "paperless-ngx.secretKeySecretName" . }}) stable, otherwise sessions and tokens are invalidated.
  Read the upstream release notes for breaking changes:
    https://github.com/paperless-ngx/paperless-ngx/releases
