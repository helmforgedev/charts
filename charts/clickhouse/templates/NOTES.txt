3. Getting started
==================
Wait for readiness:
{{- if include "clickhouse.isReplicated" . }}
  kubectl -n {{ include "clickhouse.namespace" . }} rollout status statefulset/{{ include "clickhouse.shardStatefulSetName" (dict "root" . "shard" 0) }} --timeout=10m
  {{- if include "clickhouse.keeperEnabled" . }}
  kubectl -n {{ include "clickhouse.namespace" . }} rollout status statefulset/{{ include "clickhouse.keeperFullname" . }} --timeout=10m
  {{- end }}
{{- else }}
  kubectl -n {{ include "clickhouse.namespace" . }} rollout status statefulset/{{ include "clickhouse.fullname" . }} --timeout=5m
{{- end }}

Run an HTTP query:
  kubectl -n {{ include "clickhouse.namespace" . }} run {{ include "clickhouse.fullname" . }}-query --rm -i --restart=Never --image=docker.io/curlimages/curl:8.21.0 -- curl -fsS "http://{{ include "clickhouse.fullname" . }}:{{ .Values.service.ports.http }}/?query=SELECT%201"

{{- if include "clickhouse.isReplicated" . }}
Check cluster topology:
  kubectl -n {{ include "clickhouse.namespace" . }} exec statefulset/{{ include "clickhouse.shardStatefulSetName" (dict "root" . "shard" 0) }} -c clickhouse -- clickhouse-client -q "SELECT cluster, shard_num, replica_num, host_name FROM system.clusters WHERE cluster='{{ include "clickhouse.clusterName" . }}'"
{{- end }}

7. Troubleshooting
==================
Events:
  kubectl -n {{ include "clickhouse.namespace" . }} get events --sort-by=.lastTimestamp

Server logs:
{{- if include "clickhouse.isReplicated" . }}
  kubectl -n {{ include "clickhouse.namespace" . }} logs statefulset/{{ include "clickhouse.shardStatefulSetName" (dict "root" . "shard" 0) }} -c clickhouse --tail=200
  {{- if include "clickhouse.keeperEnabled" . }}
  kubectl -n {{ include "clickhouse.namespace" . }} logs statefulset/{{ include "clickhouse.keeperFullname" . }} -c keeper --tail=200
  {{- end }}
{{- else }}
  kubectl -n {{ include "clickhouse.namespace" . }} logs statefulset/{{ include "clickhouse.fullname" . }} -c clickhouse --tail=200
{{- end }}

Configuration:
  kubectl -n {{ include "clickhouse.namespace" . }} get configmap {{ include "clickhouse.configMapName" . }} -o yaml

Common checks:
- If the pod is pending, inspect PVC binding and StorageClass availability.
- If authentication fails, verify the password Secret and restart the StatefulSet after a rotation.
{{- if include "clickhouse.isStandalone" . }}
- For multi-node clusters, set architecture=replicated with Keeper (or external ZooKeeper).
{{- else }}
- Verify system.clusters and Keeper quorum before creating Replicated* / ON CLUSTER objects.
{{- end }}
- If metrics are missing, set metrics.enabled=true and verify the Service exposes the metrics port.
