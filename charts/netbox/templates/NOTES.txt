3. Workloads

4. Initial Administrator
{{- if .Values.auth.superuser.enabled }}
   Username: {{ .Values.auth.superuser.name }}
   Password Secret: {{ include "netbox.superuserSecretName" . }}
   kubectl get secret -n {{ include "netbox.namespace" . }} {{ include "netbox.superuserSecretName" . }} -o jsonpath="{.data.{{ .Values.auth.superuser.passwordKey }}}" | base64 -d

5. Validation
   Run Helm tests:
   helm test {{ .Release.Name }} -n {{ include "netbox.namespace" . }}

6. Troubleshooting
   Inspect workloads:
   kubectl get deployments,cronjobs -n {{ include "netbox.namespace" . }} -l app.kubernetes.io/instance={{ .Release.Name }}
   Inspect recent events:
   kubectl get events -n {{ include "netbox.namespace" . }} --sort-by=.lastTimestamp

7. Production Reminders
   1. Back up PostgreSQL and the media PVC together.
   2. Do not expose Redis database 0, which carries background jobs, to untrusted clients.
   3. Use ReadWriteMany media storage or external object storage before scaling web replicas.
